# Diabetes-Predictor
This is a machine learning-powered web application built with Streamlit that predicts whether a person is likely to have diabetes based on medical input features. It also includes a basic health assistant chatbot (OpenAI GPT-based) and provides visual insights from the dataset.

# Features
1. Predict diabetes risk using Random Forest Classifier
2. Interactive sliders for user input
3. Accuracy display from trained model
4. Visual data summary and charts
5. Option to download the personal predicted report

# Tech Stack
1. Python
2. Streamlit, Scikit-Learn, Numpy, Pandas
3. Matplotlib, Seaborn

# Dataset
1. Source: PIMA Indians Diabetes Dataset
2. Columns include: Pregnancies, Glucose, BloodPressure, SkinThickness, Insulin, BMI, DiabetesPedigreeFunction, Age, and Outcome.
